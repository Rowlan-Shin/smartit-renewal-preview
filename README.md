# 세명대학교 스마트IT학부 홈페이지 리뉴얼 — 검토용 시안(임시 게시)

- 이 저장소는 **공식 사이트가 아니다.** 스마트IT학부 홈페이지 리뉴얼 참고안(1차본)을 학부 안에서 검토하려고 임시로 올린 사본이다.
- 공식 사이트: https://www.semyung.ac.kr/smartit.do
- 검토가 끝나면 이 저장소를 지운다. 검색 노출을 막는 표지(noindex)를 모든 쪽에 넣었다.
- 실제 구축은 업체가 한다. 글·사진은 현행 학부 사이트 원문에서 가져왔고, 학부 확인이 남은 항목이 있다.
- 글꼴: Pretendard(SIL OFL 1.1) · Archivo · JetBrains Mono(Google Fonts, SIL OFL 1.1). 3D: three.js(MIT).
